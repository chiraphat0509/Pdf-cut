# Smart PDF Splitter

แยก PDF ที่รวมเอกสารหลายฉบับ (ใบแจ้งหนี้ ใบสั่งซื้อ สลิปเงินเดือน Bank Statement ภาษี ฯลฯ ทั้งไทย/อังกฤษ)
ออกเป็นไฟล์รายฉบับ **ในเครื่องของคุณเอง** ไม่ส่งเอกสารออกอินเทอร์เน็ต ไม่ใช้ PDF license เชิงพาณิชย์ และไม่เรียก AI API

**ไม่มีการรับรองความแม่นยำ 100%** — ระบบให้คะแนนความมั่นใจทุกจุดตัด ทำเครื่องหมาย ⚠ จุดที่ไม่แน่ใจ
และให้คนตรวจ/แก้ก่อนส่งออกเสมอ (ผลทดสอบที่มีอยู่ดูหัวข้อ "ผลทดสอบ" ด้านล่าง)

## สิ่งที่ต้องมี (เครื่องเปล่า Windows)

| ของ | ใช้ทำอะไร | ต้องมีไหม |
|---|---|---|
| [Python 3.10+](https://www.python.org/downloads/) — ตอนติดตั้งติ๊ก **Add python.exe to PATH** | รันระบบ | ต้องมี |
| VS Code + ส่วนเสริม **Python** (Microsoft) | แก้โค้ด/รัน terminal | แนะนำ |
| [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) (ตัวติดตั้งของ UB Mannheim) — ตอนติดตั้งเลือก **Additional language data → Thai** | OCR หน้าที่เป็นภาพสแกน | ต้องมีถ้ามี PDF สแกน; PDF ที่มีข้อความอยู่แล้วไม่ต้อง |

macOS: `brew install tesseract tesseract-lang` · Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-tha`

## ติดตั้งและรัน

เปิดโฟลเดอร์โปรเจกต์ใน VS Code แล้วเปิด Terminal (`Ctrl+``) :

```powershell
py -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run.py                   # เปิดเบราว์เซอร์ที่ http://127.0.0.1:8765
```

ถ้า Windows ไม่เจอ Tesseract ให้ใส่พาธใน `config.json`:
`"tesseract_cmd": "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"`

ใช้งานจาก command line (ไม่เปิดหน้าเว็บ): `python -m splitter.cli ไฟล์.pdf --export out.zip`

## วิธีใช้
1. เลือกหรือลากไฟล์ PDF ได้หลายไฟล์พร้อมกัน ระบบจะตรวจเนื้อหาไฟล์และข้ามไฟล์ซ้ำโดยเก็บรายการแรกไว้ จากนั้นรวมและวิเคราะห์ให้อัตโนมัติ เรียงหน้าตามลำดับไฟล์ที่แสดงในรายการ เพิ่มหรือลบทีละไฟล์ หรือกด **ล้างทั้งหมด** ได้ หลังอัปโหลดแล้วใช้ปุ่ม **เพิ่มไฟล์ PDF** ในแผงรายการไฟล์เพื่อเพิ่มไฟล์ภายหลัง
2. ใช้ปุ่มลูกศรบนภาพเพื่อเลื่อนดูหน้า โดยมีเลขหน้ากำกับที่ด้านล่างภาพ หรือคลิกภาพย่อด้านล่างเพื่อเปิดหน้านั้น ภาพใหญ่แสดงด้านซ้าย ส่วนหมายเลขหน้ากับชื่อชุดและข้อความที่อ่านได้อยู่ด้านขวา
3. แก้ไข: **✂** แยกตรงนั้น · **⤴ รวม** กับก่อนหน้า · **ลากหน้า** ไปเอกสารอื่น · พิมพ์ **ช่วงหน้า** (เช่น `3-5,8`) · เปลี่ยนประเภท · ตั้งชื่อไฟล์
   หน้าที่หลุดจากทุกเอกสารจะไปอยู่ใน "หน้าที่ยังไม่ถูกจัดเข้าเอกสาร" และระบบเตือนก่อนส่งออก (ไม่มีหน้าหายเงียบๆ)
4. ค้นหาชุดเอกสารจากชื่อหรือเลขที่เอกสาร และกรองด้วยดรอปดาวน์หมวด/ชนิดเอกสาร เช่น PO, SO, Invoice และใบเสร็จรับเงิน
5. กด **⬇ ส่งออกเอกสาร** ที่แถบด้านบนเพื่อเปิดหน้าต่างเลือกชุดเอกสาร แล้วติ๊กชุดที่ต้องการและเลือกดาวน์โหลดเป็น PDF แยกไฟล์ หรือดาวน์โหลดทุกชุดเป็น PDF แยกไฟล์/ZIP ได้ ปุ่ม **⬇ บันทึกเป็น PDF** ใต้ชุดเอกสารยังใช้ดาวน์โหลดชุดเดียวได้ ทุกแบบคัดลอกหน้าต้นฉบับโดยตรง ไม่เรนเดอร์ใหม่

หากเพิ่มไฟล์หลังวิเคราะห์แล้ว ระบบจะคงไฟล์เดิมไว้ ตรวจไฟล์ใหม่เทียบกับรายการเดิม และวิเคราะห์ชุดใหม่อัตโนมัติเฉพาะเมื่อมีไฟล์ที่ไม่ซ้ำ หากรีเฟรชหน้าเว็บ งานที่อัปโหลดและการแก้ไขจะถูกกู้คืนในเบราว์เซอร์เดิม ตราบใดที่ข้อมูลของงานในโฟลเดอร์ `data/` ยังอยู่

## ตั้งค่า `config.json`
- `our_company_names`: ชื่อบริษัทของคุณ (หลายชื่อได้) — **ใส่เพื่อให้แยก "ใบแจ้งหนี้ขาย" กับ "ใบแจ้งหนี้ซื้อ" ถูกต้อง**
  ถ้าเว้นว่าง ระบบจะสมมติว่าเป็นเอกสารที่เราออก และขึ้นเตือน 60% ทุกใบ
- `ocr`: `auto` (ค่าเริ่มต้น: OCR เฉพาะหน้าที่จำเป็น) · `off` · `always`
- `ocr_dpi`: ความละเอียดตอน OCR (300 เหมาะกับเอกสารทั่วไป)

## ระบบตัดสินใจอย่างไร (อธิบายได้ทุกจุด)
**อ่านข้อความรายหน้า** — ลองดึงข้อความจาก PDF ก่อน แล้วตรวจคุณภาพ: ปริมาณข้อความ, หน้าเป็นภาพเต็ม, อักขระผิดรูป `(cid:)`,
วรรณยุกต์ไทยลอยผิดที่, หมึกมากเกินกว่าข้อความอธิบายได้ → ใช้ OCR เฉพาะหน้าที่ผิดปกติ (หน้าที่แค่น่าสงสัยจะ OCR เทียบแล้วเลือกอันที่ครบกว่า)
ทุกหน้าแสดงเหตุผลว่าทำไมเลือกวิธีนั้น · ภาษาไทยจาก PDF (เช่น Excel) ถูกแก้ปัญหาวรรณยุกต์/สระสลับตำแหน่งแล้ว

**หน้าว่าง** — ตัดสินว่าว่างเมื่อขาวสนิท หรือ OCR ยืนยันว่าไม่มีข้อความ (หน้าสแกนที่มีข้อความน้อยจะไม่ถูกทิ้ง)

**จุดตัดเอกสาร** — รวมคะแนนจากหลายสัญญาณ ไม่พึ่งคำเดียว: เลขที่เอกสารเปลี่ยน/คงเดิม, "Page x of y" / "หน้า x จาก y",
ชื่อเอกสารที่หัวหน้า, ประเภทเปลี่ยน, หัวกระดาษคล้ายหรือต่าง, ยอดรวมครบก่อนหน้า, ถัดจากหน้าว่าง,
และกรณีพิเศษ *เอกสารกว้างที่ Excel ตัดคอลัมน์ไปหน้าถัดไป* (ช่อง "เลขที่เอกสาร" ว่างในหน้าแรก แล้วไปมีค่าในหน้าถัดไป → รวมเป็นฉบับเดียว)
คะแนนต่ำกว่าเกณฑ์ = ขึ้น ⚠ ให้คนตรวจ (ค่าเริ่มต้นคือ "ไม่ตัด" เพื่อไม่ให้เอกสารขาดครึ่ง)

**ประเภทเอกสาร** — กฎคำสำคัญที่ตรวจสอบได้ (5 กลุ่ม + Other/Unknown) ถ่วงน้ำหนักที่หัวเอกสาร; ไม่พอก็เป็น Unknown ไม่เดา

## ผลทดสอบ (`python -m pytest -q`)
ไฟล์ตัวอย่างจริง 3 ไฟล์ใน `samples/` + เคสสังเคราะห์ที่รู้เฉลยใน `tests/make_cases.py` ผ่านทั้งหมดในเครื่องที่สร้าง:
ใบแจ้งหนี้ 3 ใบ, PO อังกฤษ 3 ใบ, **PO ไทยจาก Excel 2 หน้า = 1 เอกสาร**, ทั้ง 3 ไฟล์รวมกัน, เอกสารยาว 1/2/3 หน้าปนกัน (มี/ไม่มีเลขหน้า, หน้าต่อไม่มีหัว),
คั่นด้วยหน้าว่าง, PDF สแกน (OCR อังกฤษ) ทั้งแบบตรงและเอียง 2°
**ข้อจำกัดที่ยังไม่ได้พิสูจน์:** เคสสังเคราะห์เขียนโดยผู้สร้างระบบ จึงบอกความแม่นยำบนเอกสารจริงของคุณไม่ได้ —
ควรทดสอบกับเอกสารจริงอย่างน้อยกลุ่มละ 20–50 ชุด รวมไฟล์สแกนไทย · OCR ภาษาไทยยังไม่ได้ทดสอบ (ต้องติดตั้ง `tha`) ·
ไฟล์ `data/corrections.jsonl` เก็บสถิติจำนวนจุดที่ผู้ใช้แก้ในแต่ละครั้ง (ไม่เก็บเนื้อหาเอกสาร) ไว้วัดตัวชี้วัด

## โครงสร้าง
```
run.py                 เริ่มเซิร์ฟเวอร์
config.json            ตั้งค่า
splitter/reader.py     อ่านข้อความ/ตรวจคุณภาพ/OCR รายหน้า
splitter/fields.py     เลขที่เอกสาร วันที่ ลำดับหน้า ยอดรวม
splitter/classify.py   จำแนกประเภท (กฎ + หลักฐาน)
splitter/boundary.py   ตรวจจุดตัด (คะแนนหลายสัญญาณ + เหตุผล)
splitter/pipeline.py   รวมทุกขั้น + ส่งออก ZIP
splitter/server.py     เซิร์ฟเวอร์ในเครื่อง (stdlib)   web/index.html  หน้าตรวจ/แก้
tests/                 pytest + ตัวสร้างเคสทดสอบ        samples/        ไฟล์ตัวอย่างของคุณ
```

## ขั้นต่อไปที่แนะนำ
1. ทดสอบกับเอกสารจริง + ติดตั้ง `tha` แล้ววัดผล OCR ไทย (เทียบ Tesseract กับ EasyOCR/PaddleOCR เฉพาะหน้าที่ Tesseract มั่นใจต่ำ)
2. เพิ่มกฎเฉพาะของผู้ขาย/ฟอร์มที่ใช้บ่อยจาก `corrections.jsonl`
3. ใช้ AI (โมเดลในเครื่องหรือ API) เฉพาะหน้าที่คะแนนยัง ⚠ หลังผ่านกฎทั้งหมด — ยังไม่ได้ทำใน MVP นี้ ตั้งใจเว้นไว้เพื่อคุมต้นทุนและความเป็นส่วนตัว
